# Задание 1 (fork + файлы + каналы)

Иван Горбунов  
Подгруппа: 1

Программа создаёт копии файлов, имена которых переданы в аргументах командной строки, с
суффиксом `.copy`.

## Сборка

```bash
make
```

## Запуск

С неименованными каналами:

```bash
./file_copy file1.txt file2.txt
```

С именованными каналами:

```bash
./file_copy -p /tmp/file_copy_channel file1.txt file2.txt
```

## Тестирование

```bash
make test
```

Тестовые файлы и копии создаются в каталоге `demo`.

## Очистка

```bash
make clean
```

Команда удаляет объектные файлы, программу и каталог `demo`. Тестирование с последующей очисткой:

```bash
make test clean
```
