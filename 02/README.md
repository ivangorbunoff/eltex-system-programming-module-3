# Задание 2 (очереди сообщений System V + сигналы)

Иван Горбунов  
Подгруппа: 1

Программа реализует модель «Издатель-Брокер-Подписчик» с использованием одной очереди сообщений System V.

Брокер, издатели и подписчики запускаются как отдельные процессы в разных терминалах.

## Сборка

```bash
make
```

## Запуск брокера

```bash
./pubsub -b
```

## Запуск издателя

```bash
./pubsub -p <тема>
```

## Запуск подписчика

```bash
./pubsub -s <тема> [тема ...]
```

Сначала необходимо запустить брокер, затем подписчиков и издателей. Издатель читает сообщения из `stdin`.

Все экземпляры программы необходимо запускать из каталога `02`, чтобы `ftok()` сформировал одинаковый ключ.

## Очистка

```bash
make clean
```
