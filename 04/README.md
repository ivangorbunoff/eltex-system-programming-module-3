# Задание 4 (семафоры + разделяемая память System V)

Иван Горбунов  
Подгруппа: 1

Программа реализует модель «Производитель-Потребители». Производитель помещает массивы случайных чисел
в разделяемую память, а потребители находят минимальное и максимальное значения в каждом массиве.

## Сборка

```bash
make
```

## Запуск производителя

```bash
./producer_consumer -p
```

## Запуск потребителя

```bash
./producer_consumer -c
```

Все процессы нужно запускать из каталога `04`, чтобы `ftok()` сформировал одинаковые IPC-ключи.

## Очистка сборки

```bash
make clean
```
