# Задание 5 (семафоры + разделяемая память POSIX)

Иван Горбунов  
Подгруппа: 1

Программа реализует модель «Производитель-Потребители» из задания 4 с использованием именованного семафора и разделяемой памяти POSIX.

## Сборка

```bash
make
```

## Запуск производителя

```bash
./producer_consumer -p
```

## Запуск потребителя

```bash
./producer_consumer -c
```

## Просмотр POSIX IPC-объектов

```bash
ls -l /dev/shm/memory /dev/shm/sem.semaphore
```

## Очистка сборки

```bash
make clean
```
